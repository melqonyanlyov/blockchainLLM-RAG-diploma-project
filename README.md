# Blockchain և LLM/RAG տեխնոլոգիաների կիրառմամբ գիտելիքների անվտանգ պահպանման և սեմանտիկ որոնման համակարգ

Հիբրիդային թվային համակարգ, որը համադրում է **Բլոկչեյն** տեխնոլոգիան և **LLM/RAG** (Retrieval-Augmented Generation) մեխանիզմները՝ ապահովելով կորպորատիվ գիտելիքների անփոփոխելիությունը, տարբերակների վերահսկումը և հալյուցինացիաներից զերծ սեմանտիկ որոնումը։

## 🏗 Համակարգի Ճարտարապետություն

Համակարգը կառուցված է **«Հաշվարկել և պահել off-chain, ստուգել on-chain»** (*Compute and Store Off-chain, Verify On-chain*) հարացույցի հիման վրա և բաղկացած է 4 հիմնական շերտից.

1. **Ներկայացման շերտ (Frontend):** Օգտատիրոջ ինտերֆեյս՝ փաստաթղթերի վերբեռնման, ամբողջականության ստուգման և RAG չատ-օգնականի հետ աշխատելու համար։
2. **Կիրառական տրամաբանության շերտ (Backend & Orchestration):** Կառուցված է **Python / FastAPI**-ի հիման վրա, կառավարում է տվյալների հոսքը, **RBAC** (դերային մուտքի վերահսկում՝ Admin, Content Manager, User) և կապը բլոկչեյնի հետ (**Web3.py**)։
3. **Արտաքին պահպանման շերտ (Off-Chain Storage):**
   * **PostgreSQL**՝ օգտատերերի տվյալների, փաստաթղթերի մետատվյալների և գործարքների հեշերի պահպանման համար։
   * **Vector DB (ChromaDB / FAISS)**՝ տեքստային հատվածների (chunks) և դրանց վեկտորային ներկայացումների (embeddings) գերարագ HNSW որոնման համար։
4. **Ապակենտրոնացված վստահության շերտ (On-Chain):** EVM-համատեղելի բլոկչեյն ցանց և **Solidity** խելացի պայմանագիր (Smart Contract), որտեղ գրանցվում են փաստաթղթերի 64-նիշանոց **SHA-256** կրիպտոգրաֆիկ հեշերը և տարբերակների պատմությունը։
